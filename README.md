# Прикладні ШІ-агенти та системи на основі великих мовних моделей

HTML-версія магістерського курсу КПІ ім. Ігоря Сікорського, спеціальність 122.
Вісімнадцять лекцій, п'ять лабораторних, інтерактивні вставки й реальний вивід прикладів коду.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:5173
```

`npm run build` збирає статику в `.vitepress/dist`, `npm run preview` показує зібране.

## Звідки береться вміст

Джерело курсу одне — `../course-gamma-2026/decks-v2/lecture-NN.src.md`.
З нього складаються і колоди Gamma, і цей сайт, тому розійтися вони не можуть.

```bash
cd ../course-gamma-2026
python3 tools/run_examples.py     # прогнати приклади коду, записати фактичний вивід
python3 tools/build_site.py       # .src.md → lectures/NN.md
cd ../course-site && npm run build
```

Редагувати треба **`.src.md`**. Файли в `lectures/` генеруються і перезаписуються.

## Публікація

Workflow `.github/workflows/deploy.yml` збирає й публікує на GitHub Pages при пуші в `main`.
У налаштуваннях репозиторію: **Settings → Pages → Source → GitHub Actions**.

Якщо сайт живе за адресою `user.github.io/<репозиторій>/`, workflow сам підставляє
`BASE=/<репозиторій>/`. Для власного домену або кореневої адреси змінну можна не задавати.

## Керування на парі

Клавіша <kbd>P</kbd> — режим презентації: більший шрифт, приховані бічні панелі.
Клік по будь-якій схемі відкриває її на весь екран, <kbd>Esc</kbd> закриває.

Сайт статичний: теку `.vitepress/dist` можна покласти на флешку й відкрити локальним
сервером, якщо в аудиторії немає інтернету.
